7. SMC Engine – Active Rules & Live Diagnostics

−

This panel documents the rules that are actually implemented in scanner.py. It does not imply that every concept from SMC / ICT theory is currently detected.

1. 5-minute market structure BOS: completed 5m close breaks the prior 10-bar high/low. MSS proxy: BOS occurs against the preceding 5-close slope. When no fresh break exists, direction may fall back to a 20-bar range position and 5-vs-15 close averages.
2. 2-minute Fair Value Gap Three-candle gap checked over the latest 12 bars. Uses the gap zone only while a later close has not invalidated it; current 2m candle must overlap the zone for a retest.
3. 2-minute Order Block Last opposite-colour candle before a directional displacement candle. Displacement body must be at least 1.3× the average body of the preceding five candles; search lookback is 10 bars. Later close through the far edge invalidates the zone; current candle overlap is the retest test.
4. 2-minute IDM / liquidity proxy Checks the prior 12-bar internal high/low, excluding the current candle. Requires a wick sweep and a close back inside the range, in the expected direction.
5. 1-minute entry confirmation Bullish: green candle closes above the previous three 1m highs. Bearish: red candle closes below the previous three 1m lows. Only completed candles are used.
6. Final signal gate 5m direction + (2m FVG retest OR OB retest) + (IDM sweep OR BOS/MSS) + 1m trigger + entry-time filter. Code time filter: 09:30–11:50 IST.
